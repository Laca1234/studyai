# StudyMind AI

Modern AI-powered study platform prototype built with Next.js, Tailwind CSS, and Framer Motion.

## Features

- Landing page for AI study onboarding
- Authentication pages (login, register, forgot password)
- Student dashboard with progress modules
- Study planner, AI tutor, flashcards, quizzes, and mock exam concept pages
- Dark/light-friendly premium SaaS UI

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open `http://localhost:3000`

## Notes

This workspace is scaffolded as a startup-ready frontend concept. The app includes responsive pages and UI patterns for Hungarian high school and university student workflows.
